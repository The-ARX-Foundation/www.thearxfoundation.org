# tools/

Build tooling. It isn't served: `.assetsignore` keeps `tools/` out of the deployed site.

`build_projects.py` builds `projects/index.html` (public) plus a private triage view, from:
- the ARX catalog (`Documents/ARX Projects/catalog.json`, generated by `_tools/arx_catalog.py`),
- a snapshot of the triage board (`ArtifactData list` → JSON files),
- `Documents/ARX Projects/code-links.json`.

```bash
A="/media/elryan/The Arxives/TAoTE/Documents/ARX Projects"
python3 tools/build_projects.py --catalog "$A/catalog.json" --board "$A/_site-private/board" \
  --links "$A/code-links.json" --public-out projects/index.html --private-out "$A/_site-private/index.html"
```

Only projects with `visibility_set == "public"` on the board reach the public page. Personal-category items, placeholders, money, notes, paths, chat links, private markers and legal/IP fields are always stripped. The script refuses to write the private view inside this repo.
