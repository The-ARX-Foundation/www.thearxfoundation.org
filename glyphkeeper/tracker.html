Project Roadmap

Glyphkeeper is being built in phases. Each script gets a full interactive learner with history, character chart, flashcards, and quiz. The final phase builds translational bridges between every script.

PHASE 1

Interactive Learners — Syllabaries

Build out all 8 syllabary learners. ✅ COMPLETE — 8/8 built (Bamum, Cherokee, Japanese Kana, Yi, Vai, Canadian Aboriginal, Mende Kikakui, Linear B).

PHASE 2

Interactive Learners — Logographic & Pictographic

Chinese Hanzi (radicals-first approach), Japanese Kanji, Egyptian Hieroglyphs, Cuneiform, Maya Glyphs, Naxi Dongba. Heavy research phase — these scripts have thousands of characters each. Starter sets of 100–200 most common characters per script.

PHASE 3

Interactive Learners — Abugidas & Unique Systems

Ge'ez, Tibetan, Devanagari, Hangul, Sundanese, Georgian, N'Ko. These scripts have elegant internal logic (vowel modification systems) that can be taught systematically.

PHASE 4

Interactive Learners — Ancient & Undeciphered

Phoenician, Linear A (what we know of it), Elder Futhark. Historical context and archaeological framing. Linear A gets a special "mystery mode" since it's undeciphered.

PHASE 5

Translational Models & Global Lexicon

Brute-force train translational mappings between character sets. Phonetic bridging — map every script's syllable inventory to IPA, then cross-reference. Build the Global Lexicon: a unified reference where any concept can be expressed in any script. Feed these mappings into LLM tooling so code and conversation can flow through any character set. The endgame: every writing system as a first-class citizen in computation.

PHASE 6

Open Source & Community

Package everything as an ARX Foundation open-source project. Invite native speakers and linguists to contribute corrections, audio recordings, and expanded character sets. Deploy as a progressive web app with offline support. Pitch to language revitalization programs (Cherokee Nation, Bamum Scripts and Archives Project, etc.).
