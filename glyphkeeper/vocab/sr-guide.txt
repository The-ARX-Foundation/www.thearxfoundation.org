GLYPHKEEPER SPACED REPETITION SYSTEM
Integration Guide v0.1

=== OVERVIEW

Two-component learning system:
1. SR Dashboard (glyphkeeper-sr-dashboard.html) — Mission control
2. Unified Learner (glyphkeeper-learner.html) — Review sessions

Both use browser localStorage for persistence (no account needed, no cloud sync).

---

=== COMPONENT 1: SR DASHBOARD

Displays global stats + per-script progress tracking.

STATS TRACKED:
• Total characters learned / remaining
• Mature cards (mastered)
• Cards due today / this week / this month
• Average ease factor (how easy cards are to recall)
• Estimated days to completion
• Progress by writing system

VIEW:
- Launch: glyphkeeper-sr-dashboard.html
- Click "Start Review" → Opens learner for due cards

EXPORT/IMPORT:
- Export: Downloads JSON snapshot of all SR data
- Import: Load previous session data
- Reset: Clears all progress (caution: irreversible)

---

=== COMPONENT 2: UNIFIED LEARNER

Interactive review session with glyph→meaning reveal flow.

WORKFLOW:
1. Select writing system (Mandarin, Yi, Vai, Egyptian, Japanese)
2. System builds queue: due cards first, then new cards
3. For each card:
   a. See glyph/character (front of card)
   b. Click to reveal: meaning, transliteration, readings (back of card)
   c. Rate yourself 0-5:
      - 0 = Forgot completely
      - 1 = Very hard
      - 2 = Difficult
      - 3 = Fair / acceptable (card passes)
      - 4 = Good
      - 5 = Perfect / immediate recall
4. SM-2 updates based on rating (see algorithm below)
5. Session ends when queue is empty
6. Shows: cards reviewed, accuracy %, current streak

CARD STATES:
• New — Never reviewed
• Learning — Reviewed but interval < 21 days
• Review — Interval >= 21 days, not yet mature
• Mature — Interval > 6 months, ease >= 2.0 (mastered)

---

=== SM-2 SPACED REPETITION ALGORITHM

The Anki algorithm. Every card has:

PARAMETERS:
• interval (days until next review) — starts at 1
• ease_factor (0.3 - ∞, default 2.5) — how easily recalled
• repetitions (count of successful recalls) — tracks streak
• next_review (ISO timestamp) — when to show next
• state (new | learning | review | mature) — current stage

UPDATE FORMULA (on response):

If quality >= 3 (PASS):
  if repetitions == 0:
    interval = 1
  elif repetitions == 1:
    interval = 6
  else:
    interval = round(interval * ease_factor)
  
  repetitions += 1
  ease_factor = max(1.3, ease_factor + (0.1 - (5-quality) * (0.08 + (5-quality)*0.02)))
  
  if repetitions >= 2 AND interval > 20:
    state = 'mature'
  else if repetitions >= 1:
    state = 'review'
  else:
    state = 'learning'

If quality < 3 (FAIL):
  repetitions = 0
  interval = 1
  state = 'learning'
  (ease_factor unchanged)

next_review = now + interval days

INTERPRETATION:
- Quality 5 → ease grows fastest, interval jumps most
- Quality 4 → normal ease growth
- Quality 3 → slow ease growth, card still passes
- Quality 0-2 → reset to beginning, try again tomorrow
- Forgotten cards get flagged for extra review

=== ADDING MORE SCRIPTS / CHARACTERS

The learner currently contains sample data (top 20 chars per script).

To add full script support:

1. In glyphkeeper-learner.html, expand SCRIPT_DATA object:

   vai_full: {
     name: 'Vai Syllabary (Full)',
     chars: [
       { g: 'ꕙ', m: 'a', py: 'a' },
       { g: 'ꔞ', m: 'e', py: 'e' },
       ... 220 total
     ]
   }

2. Characters auto-initialize on first review:
   - Storage.js creates SM-2 state if missing
   - Reads from localStorage
   - Persists across sessions

3. Can load JSON from external learner files:
   - fetch('yi-expanded.html') → parse char data
   - Merge into SCRIPT_DATA
   - Same localStorage key = unified tracking

ARCHITECTURE:
```
Dashboard
    ↓ (displays)
localStorage[glyphkeeper_sr_data]
    ↑ (reads/writes)
Learner
```

=== DATA STORAGE FORMAT

localStorage key: "glyphkeeper_sr_data"

Structure:
```json
{
  "mandarin": {
    "0": { interval: 1, ease_factor: 2.5, repetitions: 0, next_review: "...", state: "new" },
    "1": { interval: 6, ease_factor: 2.6, repetitions: 1, next_review: "...", state: "learning" },
    ...
  },
  "yi": {
    ...
  }
}
```

Storage limit: ~5-10 MB (supports 50,000+ cards)
Browser: Chrome, Firefox, Safari all support localStorage
Fallback: None — use export/import to backup

=== TIPS FOR EFFECTIVE LEARNING

1. Consistent daily reviews (10 min/day > 2 hours/week)
   → SM-2 math assumes regular practice
   → Spacing benefit decreases if reviews are irregular

2. Be honest with ratings
   → If you hesitate > 10 sec: rate 2 or 3, not 4
   → Perfect recall = 5, good recall but needed think = 4
   → Don't inflate scores; learning improves faster with accurate feedback

3. Watch ease factor
   → Cards averaging 2.0 ease → take longer to mature (OK for hard scripts)
   → Cards averaging 3.0+ ease → fast progression to mastery
   → Very low ease (< 1.5) → consider removing or simplifying

4. Use export before major changes
   → Save progress JSON before adding/removing scripts
   → Can import to restore state

5. Daily goal: 20-30 cards/day
   → Reaches ~1k characters maturity in ~6 months
   → Adjustable based on time available
