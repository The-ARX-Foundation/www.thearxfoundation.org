§ 01The Problem

The music industry is broken at every layer. Streaming platforms optimize for engagement — time-on-platform, ad exposure, skip rate minimization — not for the listener's actual experience. Artists receive roughly $0.003–$0.005 per stream, with ~15% of subscriber revenue reaching them after label recoupment. The algorithms push what's popular, not what's meaningful.

You don't own anything. Your library is a rental agreement that can be revoked at any time. Your playlists are trapped. Your volume control doesn't work the way you expect. Headphone buttons control the wrong thing. And the lyrics you're absorbing? No one's auditing those for the messages they carry.

"The music industry doesn't need another player. It needs a protocol." — The founding premise of SoundWeave.

§ 03Why Non-Profit

A for-profit streaming company is structurally incentivized to minimize artist payout and maximize engagement metrics for advertisers. SoundWeave under a 501(c)(3) flips the incentives: all surplus is reinvested, artist compensation is the primary mission, and the lifetime license trust fund is legally protected from shareholder pressure — because there are no shareholders.

Non-profit status also provides reduced PRO licensing rates and positions SoundWeave as a public-benefit platform, not a competitor to be crushed.

§ 02Required Licenses (US Non-Profit)

Regardless of streaming backend, operating an interactive music streaming service in the US requires licenses from four categories of rights holders. Non-profit status helps with rates but does not exempt from any of these.

Mechanical License (MLC)
Blanket license via the Mechanical Licensing Collective, established by the Music Modernization Act (2018). Required for all interactive streaming. MLC administers, collects, and distributes.
Performance Rights (PROs)
Separate licenses from ASCAP (1.1M+ members), BMI (1.4M+ songwriters), and SESAC. BMI explicitly confirms non-profit status does not exempt from licensing. Typically 1-year terms with minimum annual fees.
Sound Recording (SoundExchange)
For non-interactive streaming; interactive (on-demand) requires direct deals with labels/distributors. SoundExchange offers "WSA rates" with simplified reporting for qualifying webcasters.
Sync License
Only required if combining music with visual media (music videos, visualizers). Not needed for pure audio streaming. Relevant for future lyric visualization features.
Strategy: Tidal SDK handles sound recording licensing for MVP (their agreements cover it). PRO licenses (ASCAP/BMI/SESAC) and MLC blanket license are required regardless. Budget ~$2,000–$5,000/year for initial non-profit tier licensing before scale.

§ 02Flow State Algorithm

Current streaming algorithms optimize for engagement. SoundWeave's Flow Engine optimizes for flow state — the psychological state of complete absorption, as defined by Csikszentmihalyi. In music listening, this means no jarring transitions, gradual emotional arcs, BPM continuity with intentional drift, and key compatibility via the Camelot wheel.

The Valence-Arousal model (Russell, 1980) maps all emotional states onto two axes: valence (positive/negative) and arousal (high/low energy). Flow Engine navigates this space deliberately — not randomly.

Feature vector per track — extracted via Essentia (AGPL-3.0) audio analysis library on locally cached files:

// Track Feature Vector { valence: float [0, 1] // emotional positivity energy: float [0, 1] // arousal/intensity bpm: float // tempo key: int [0, 11] // pitch class mode: int [0, 1] // major/minor danceability: float [0, 1] acousticness: float [0, 1] spectral_contrast: float[] // timbral texture harmonic_progression: float[] // chord change rate } // Flow Transition Score (current → candidate) flow_score = w1 * valence_continuity(c, n) + w2 * energy_trajectory(c, n, intent) + w3 * bpm_proximity(c, n) // ±5% preferred + w4 * key_compatibility(c, n) // Camelot distance + w5 * spectral_similarity(c, n) + w6 * novelty_bonus(n, history) // prevent loops - w7 * jarring_penalty(c, n) // large deltas // Intent modes (user-set or auto-detected): intent ∈ { sustain, energize, wind_down, explore, focus }
§ 03Reinforcement Learning Layer

On top of the rule-based flow scoring, a reinforcement learning agent (inspired by Moodify's go-explore strategy, tested on 1M Spotify playlists) learns individual preferences over time:

Reward Signals
Session duration without skip, explicit thumbs-up, replay, adding to library. These are positive signals that the flow is working.
Penalty Signals
Skip within 15 seconds, session abandonment, explicit thumbs-down. These indicate a broken transition or poor match.
State Space
Current position in valence-arousal space, session duration, time-of-day, intent mode, listening history context window.
Open-Source Foundations
PersonalAIs (GSoC 2025) — mood-aware recs via LLMs. Essentia (MTG) — audio feature extraction. ListenBrainz — open scrobble data. All forkable.

§ 01Bringing Back Ownership

Music used to be physical. You could buy a CD, lend it to a friend, sell it at a garage sale, donate it to a library. Streaming killed all of that. SoundWeave brings it back — digitally, with cryptographic guarantees.

The key insight: use blockchain infrastructure, but never say "blockchain" to the user. Buy with a credit card. Transfer via username. The on-chain token is invisible unless you want to see it.

Stream License
Standard streaming access via subscription. No ownership, no transfer. Music available while subscription and catalog licenses hold. This is the "Spotify equivalent" tier.

Purchase License
One-time buy. Stored locally + synced to your NAS. Transferable — gift, sell, or lend to another user. Transfer is true transfer: sender loses access, receiver gains it. Backed by Solana token.

Artist releases N numbered copies. Scarcity creates value. Secondary market with 10% artist royalty on every resale. The vinyl collector model, digitized. Artists choose the edition size.

§ 02NAS Sync & Full Trust Mode

When a user enables Full Trust Mode, purchased tracks are auto-downloaded in FLAC to local storage and synced to their configured NAS via Syncthing. A cryptographic license proof is stored alongside every audio file. If SoundWeave ever ceases operations, the user retains full access to everything they've purchased — no platform dependency.

// Full Trust Mode — NAS Auto-Sync Architecture user enables Full Trust Mode: ├── Auto-downloads purchased tracks to local device ├── Syncs to NAS via Syncthing / WebDAV / SFTP │ ├── FLAC lossless audio │ ├── metadata.json (credits, license proof) │ └── license_token.sig (cryptographic proof of purchase) ├── NAS = authoritative backup │ └── Platform goes down → user retains everything └── Escrow provision: └── Third-party trustee holds catalog decryption keys → Released to license holders on platform dissolution
