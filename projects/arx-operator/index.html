▶ 5.3 — Create wallet + get HNS requires 5.2 synced pending

You need HNS tokens to bid on names. Even small amounts work — auctions are second-price Vickrey, so if you're the only bidder you pay near zero.

wallet setup

# get a receive address

# check balance (after depositing HNS)
hsw-cli --api-key $HSD_API_KEY balance

▶ 5.5 — Bid, reveal, register requires 5.4 pending
⚠ CRITICAL: You MUST run sendreveal within 10 days of bidding closing or you permanently lose the locked bid coins.
auction lifecycle (~15 days total)
# State: BIDDING (5 days)
# bid = actual bid, lockup = blind (obfuscates real bid)
# Set lockup high — makes sniping harder
hsw-cli --api-key $HSD_API_KEY rpc sendbid arx 50 500

# State: REVEAL (10 days)
# Run this as soon as state flips to REVEAL
hsw-cli --api-key $HSD_API_KEY rpc sendreveal arx

# Check if you won
hsd-cli --api-key $HSD_API_KEY rpc getnameinfo arx | jq .info.state
# → CLOSED (you won) or CLOSED (someone outbid)

# If won: register the name
hsw-cli --api-key $HSD_API_KEY rpc sendupdate arx \
  '{"ns":["ns1.arx. 172800 IN A YOUR_HETZNER_PUBLIC_IP"]}'
