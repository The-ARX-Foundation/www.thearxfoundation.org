⊙
Fixed Geometry Problem

OEM armrests are engineered as styling trim, not ergonomic interfaces. Height, angle, and fore-aft reach are all fixed at manufacturing. The center console is optimized as a storage lid first — the padded surface is an afterthought at a fixed elevation that suits a 5'10" male, not a 5'3" female driver.

◈
Anthropometric Exclusion

Shorter drivers — disproportionately women — cannot rest their left arm on the door without raising their shoulder, creating chronic trapezius tension. The center console sits at mid-torso height, forcing a choice between hunching or floating unsupported across the entire drive.

◎
Aftermarket Void

The aftermarket is nearly empty. Crude foam console toppers exist. Universal armrest extenders attempt height adjustment with cheap plastic ratchets. No product addresses door armrest elevation. No product integrates sensor-driven auto-positioning. The entire category is untouched by intelligent design.

⊗
Health Consequence

Unsupported arm posture during extended driving contributes to rotator cuff fatigue, thoracic outlet syndrome, and chronic neck tension — especially for shorter occupants who grip the wheel with elevated shoulders as compensation for absent lateral support.

⊕
Luxury OEM Near-Miss

Mercedes S-Class and BMW 7 Series offer seat memory profiles tied to key fobs. None extend this logic to armrests. The seat moves; the console stays frozen. The door panel stays frozen. Profile-aware peripheral adjustment is a genuinely open space even in the luxury segment.

⊞
Market Opportunity

The global automotive aftermarket accessories market exceeds $500B. Ergonomic and comfort segments are among the fastest-growing categories. A universal-fit, sensor-driven adaptive armrest system with BLE profile management has no direct competitor and addresses a pain point experienced by hundreds of millions of drivers daily.

The armrest has been treated as a passive styling element for 80 years of automotive design. The insight driving Project ERGON: it should be a dynamic peripheral of the occupant support system — aware of who is sitting, responsive to their geometry, and configurable to their preference profile.

Product Concept

ERGON-A1 Adaptive Armrest Module // Universal Fit Platform

F-01

Vertical Height Actuation

Lead screw linear actuator beneath the armrest pad provides 60mm of vertical travel — covering the full anthropometric gap between 5th and 95th percentile seated elbow height. Low-current 12V DC draw, near-silent operation.

Hardware
F-02

BLE User Profile System

Phone proximity detection via BLE beacon identifies the driver before door opens. Retrieves stored profile: seat height, armrest elevation, angle, fore-aft reach. All adjustments complete before the driver is seated.

Software
F-03

Seat Weight Sensor Integration

OBD-II tap reads existing SRS seat weight sensor to classify occupant size tier (light / medium / heavy). Used as a secondary confirmation and for initial setup of a new profile without phone pairing.

Sensing
F-04

Articulating Angle Pad

Pad surface has 15° of angular adjustment — tilting inboard for a narrower console reach, or outboard for drivers who prefer external elbow resting. Spring-loaded detent positions; no motor required for angle.

Hardware
F-05

Universal Fit Architecture

Mounts to existing door armrest screws via vehicle-specific adapter plates (laser-cut aluminum). No cutting, no drilling, no permanent modification. Full reversibility. Target SKUs cover 90%+ of 2005–2024 vehicles.

Integration
03 //

Technology Stack

Component architecture for ERGON-A1 platform

Layer 01 // Sensing
Occupant Detection
  • BLE 5.0 beacon — phone proximity for primary ID (±0.5m accuracy)
  • OBD-II PID read of SRS seat weight sensor — passive, no CAN interference
  • Optional: IR proximity sensor in headliner for seated height estimation
  • Fallback: manual one-button profile cycle on armrest leading edge
Layer 02 // Compute
Control Unit
  • ESP32-S3 microcontroller — BLE 5.0, Wi-Fi, dual-core, $4 BOM cost
  • Profile storage: onboard flash, up to 16 user profiles
  • OTA firmware updates via phone app Bluetooth connection
  • 12V automotive input → onboard 3.3V / 5V regulation
Layer 03 // Actuation
Motion System
  • Lead screw linear actuator — 60mm travel, 5mm/s, 200N load rating
  • DRV8833 dual H-bridge driver — current-limited, stall-detection
  • Hall effect limit switches at both travel extremes — no skip counting
  • Angle pad: spring-detent passive articulation, 5 positions × 3°
Layer 04 // Interface
User Experience
  • ARX ERGON companion app (iOS / Android) — profile setup and management
  • Haptic feedback pulse on armrest surface when profile loads
  • LED status ring (single RGB LED, diffused) — amber = loading, green = set
  • Voice command integration via CarPlay / Android Auto deep link (v2)
