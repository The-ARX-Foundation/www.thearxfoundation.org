§ 01

Problem Statement

Every van lifer, overlander, and dispersed camper currently relies on a fragmented stack of proprietary apps to answer one question: Can I safely and legally be here?

iOverlander went subscription in 2024 ($60–100/year), broke trust with the community that built its database, and still doesn't carry the data that matters most: USFS closure orders, BLM shooting restrictions, fire prevention orders, dispersed camping legality boundaries, and real-time hazard information. You can find a campsite, but you can't find out that the campsite is inside an active firearms restriction zone until someone's shooting next to your tent.

Origin Event

March 23, 2026 — Ward Canyon Road, Salt Lake Ranger District. Active firearms discharge by multiple groups in a zone covered by a standing USFS prohibition order (36 CFR 261.58(m)). No app, no signage, no enforcement. The regulatory data exists. It's published. It's just not in any tool that people actually use in the field.

The core failure is architectural: campsite apps treat public lands as a consumer product (find a spot, rate it, move on) rather than as a regulatory environment with rules that change by jurisdiction, season, and active order. The data exists — USFS publishes forest orders, BLM publishes geospatial data in GeoJSON/KML/Shapefile, state agencies publish fire restrictions — but nobody aggregates it into a field-usable interface.

§ 02

Thesis & Positioning

Waystone is a sovereign, self-hosted public lands intelligence platform. Not a campsite finder — a field operations layer for anyone who lives, travels, or recreates on public land.

Three Data Tiers

Tier Source Examples
Official / Authoritative USFS, BLM, NPS, state agencies Forest orders, fire restrictions, shooting closures, land ownership boundaries, dispersed camping rules, seasonal road closures
Crowdsourced / Community User submissions, OSM imports Campsites, water sources, cell coverage, road conditions, hazard reports, noise levels, safety notes
Derived / Computed Waystone engine Legality scores per-coordinate, seasonal access windows, "can I shoot here?" / "can I camp here?" boolean layers, distance-to-service calculations
Core Differentiator

Waystone is the only platform that answers regulatory questions ("is this legal?") alongside practical questions ("is this a good spot?"). The official data tier is not a nice-to-have — it's the entire reason this project exists.

The Scraping Problem

USFS forest orders — the most critical data for regulatory awareness — are published as HTML pages and PDF documents on per-forest websites. There is no unified API. Each national forest publishes orders in a different format, at a different URL structure, with different update cadences. This is the hardest data pipeline in the system and the one that creates the most value.

Architecture Decision

Forest order ingestion requires a scraper fleet (one per national forest) that monitors USFS alert pages, extracts order text + geospatial boundaries, normalizes into a unified schema, and flags changes. This is a cron job + LLM extraction pipeline: scrape HTML → Claude API extracts structured data (order type, CFR reference, affected area description, effective dates) → geocode area descriptions → store as GeoJSON features with metadata.

POI Schema

{
  "id": "uuid",
  "type": "campsite | water | hazard | restriction | trailhead | service",
  "geometry": GeoJSON Point | Polygon,
  "source_tier": "official | community | derived",
  "source_ref": "URL or citation",
  "properties": {
    "name", "description",
    "legal_status": "permitted | restricted | prohibited | seasonal | unknown",
    "cfr_reference": "36 CFR 261.58(m)",
    "effective_date", "expiration_date",
    "managing_agency": "USFS | BLM | NPS | state",
    "district", "forest",
    "tags": ["firearms", "fire", "camping", "road-closure"],
    "cell_coverage", "elevation", "road_surface"
  },
  "reviews": [{ user, rating, text, date, photos }],
  "verification": {
    "last_confirmed", "confidence_score", "report_count"
  }
}

§ 06

Feature Map

"Can I…?" Query Engine

The killer feature. Tap any point on the map and Waystone resolves: managing agency, active restrictions, dispersed camping legality, firearms discharge rules, fire order status, seasonal access windows, and nearest services. All from the official data tier, supplemented by community reports.

Restriction Overlay

Toggle-able polygon layers showing active forest orders, fire restrictions, and closure areas. Color-coded by type (red = firearms prohibition, orange = fire restriction, yellow = seasonal closure). Updated by the scraper pipeline. Each polygon links to the source order document.

Offline Regional Packs

Download a region (state, national forest, BLM field office) as a single offline bundle: tile extract + POI database + active restriction polygons. Service worker serves from local cache. Sync delta updates on reconnect. Critical for areas without cell coverage — which is most of public land.

Community POI Layer

iOverlander-style crowdsourced data: campsites, water sources, dump stations, road conditions, cell coverage reports. But with a key difference — every community POI is spatially intersected against the official layer, so submissions are automatically tagged with applicable restrictions.

MCP Integration

Waystone MCP server exposes tools for Claude / ARXd: query_restrictions(lat, lng), find_campsites(bbox, filters), check_legality(lat, lng, activity), get_active_orders(forest, district). Enables natural language queries like "can I camp and shoot near Ward Canyon Road?"

Report-to-Authority Pipeline

See a violation? Tap to report. Waystone auto-populates the managing agency, applicable order/CFR reference, your GPS coordinates, and a draft complaint. One-tap email to the relevant ranger district. The Ward Canyon workflow, productized.

§ 07

Phased Roadmap

Phase 0 — Foundation
Prerequisite: Hetzner VPS deployed

Docker Compose service definition. PostgreSQL + PostGIS container. Protomaps tile file (US extract, ~30GB). Basic NestJS API scaffold. MapLibre frontend rendering tiles from local PMTiles. Proof of concept: render BLM SMA boundaries on the map alongside OSM base tiles.

Phase 1 — Official Data Ingestion
2–4 weeks after Phase 0

BLM GIS Hub data download + PostGIS import (surface management, public land access, recreation areas). PAD-US import. NPS API integration. First USFS scraper targeting Uinta-Wasatch-Cache National Forest (home turf, known data structure). "Can I…?" query for a single coordinate returning land ownership + managing agency.

Phase 2 — Forest Order Pipeline
2–4 weeks after Phase 1

USFS forest order scraper generalized to multiple forests (start with UT/CA forests for van life route coverage). Claude API extraction pipeline: HTML → structured order data → GeoJSON polygons with metadata. Restriction overlay rendering on map. Daily cron refresh. Backfill historical orders for the target forests.

Phase 3 — PWA + Offline
2–4 weeks after Phase 2

Service worker implementation. Regional offline pack generation (per-forest tile extracts + POI bundles). Cache-first rendering. Sync queue for offline-created POIs. Installable PWA on GrapheneOS via IronFox. Field test on FL→UT Sprinter drive.

Phase 4 — Community Layer
Post-initial field testing

User accounts (OIDC). Community POI submission with photo upload. Auto-intersection against official data on submit. Rating/verification system. OSM campsite import pipeline. iOverlander GPX data import (historical community data, GPLv3 conversion tool exists). MCP server for Claude/ARXd integration.

Phase 5 — Report Pipeline + Scale
Ongoing

Report-to-authority one-tap workflow. NIFC wildfire data integration. Expand scraper fleet to all 154 national forests. Public instance option (separate from private Tailscale instance). Capacitor packaging for F-Droid distribution. API for third-party integrations.

§ 08

Prior Art & Differentiation

AppStrengthsFatal Gap
iOverlander Largest crowdsourced database. International coverage. Proprietary. $60–100/year subscription. No official data. No regulatory layer. Broken 2024 rebuild alienated community.
Dispersed Official USFS/BLM campsite data. Half the price. Proprietary. Campsite-only — no restriction data, no shooting/fire orders. No community layer.
The Dyrt BLM/USFS boundary overlays. Good reviews. Proprietary. Free camping filters paywalled. No active order/restriction data.
Gaia GPS Powerful mapping. Topo + public land layers. Proprietary. Mapping tool, not POI platform. No campsite database. No regulatory intelligence.
FreeRoam Community-focused. Free. Small database. No official data layer. No offline support.
OpenCampingMap FOSS. OSM data. Self-hostable. Campsite-only. No restriction data. No community features. Minimal UI.
TRIP FOSS. Self-hostable. Docker. Clean. Generic POI tracker. No public lands data. No regulatory layer. Good bones though — possible component.
Positioning

Waystone is not competing with iOverlander on campsite count. It's competing on a dimension none of them occupy: regulatory intelligence. "Is this legal?" is a question no existing app answers reliably. Waystone answers it from authoritative sources, offline, for free, self-hosted.

§ 09

Governance & Licensing

Waystone is an ARX Foundation project. AGPL-3.0 license (copyleft ensures forks stay open; AGPL covers the server-side component that iOverlander-style companies would otherwise close-source).

Repo Tiering

LayerContent
L1 — ForgejoSource of truth. All development happens here. Scraper fleet configs, API keys (via Infisical), deployment manifests.
L2 — GitHubPublic mirror. Community contributions, issues, PRs. CI/CD triggers. Documentation site.
L3 — RadicleP2P sovereign backup. Survives platform deplatforming.

Data Licensing

Official government data (BLM, USFS, NPS) is public domain — no licensing restrictions. OSM data is ODbL (attribution + share-alike for derivative databases). Community-submitted POIs are CC BY-SA 4.0, ensuring the community database can never be enclosed by a proprietary fork.

Sustainability Model

ARX Foundation 501(c)(3) nonprofit. No subscription fees. No ads. Revenue paths: grants (NSF, recreation/conservation foundations), donations, and optional managed hosting for organizations (ranger districts, outdoor education nonprofits, SAR teams) who want Waystone without running their own server.
